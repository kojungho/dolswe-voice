# 돌쇠 음성비서 1.0.2

갤럭시용 별도 앱입니다. 캠핑 장부나 Home Assistant 앱을 열어두지 않아도 됩니다.
Android 10 이상, ARM64 기기용입니다.

## 처음 연결

1. `dolswe-voice.apk`를 휴대폰에 다운로드해 설치합니다.
2. HA 프로필 → 보안 → **장기 액세스 토큰**에서 앱용 토큰을 만듭니다. 토큰은 앱에만 입력하고 다른 사람에게 보내지 마세요.
3. 앱 **설정**에 HA HTTPS 주소, 토큰, **HA에 만들어 둔 레이블 이름**을 입력합니다.
4. **장치 별칭 → HA 장치 목록 불러오기**를 누릅니다.
5. 사용할 항목에 앱에서 부를 이름을 입력하고 **장치 별칭 저장**을 누릅니다. 예: `거실 불`, `안방 선풍기`.
6. **호출어 인식 테스트**로 `돌쇠야`, `이모님`의 인식 결과를 확인합니다.
7. **호출 대기 시작**을 누르고 마이크·알림 권한을 허용합니다.
8. 처음에는 **시험 모드**로 연결만 확인합니다. 실제 제어는 설정에서 시험 모드를 끄고 저장한 뒤 호출 대기를 다시 시작하세요.

토큰을 다시 입력하지 않고 설정만 바꿀 때는 토큰 칸을 비워 둡니다.
레이블은 이름 또는 HA 레이블 ID를 입력할 수 있습니다. 엔티티에 붙인 레이블과 장치에 붙인 레이블을 확인합니다. 장치 레이블은 그 장치의 지원 항목들을 불러옵니다. 그룹은 제외합니다.

## 말하는 예

- `돌쇠야, 거실 불 켜줘`
- `이모님` → “네, 말씀하세요” 후 `안방 선풍기 꺼줘`
- `돌쇠야, 거실 불 밝기 50퍼센트로 맞춰줘`
- `이모님, 에어컨 온도 25도로 맞춰줘`
- `돌쇠야, 거실 불 상태 알려줘`
- `이모님, 침실 커튼 닫아줘`

등록한 별칭을 문장 앞에 말하세요. 한 번에 한 장치씩 제어합니다.
호출어는 설정에서 쉼표로 구분해 1~10개로 바꿀 수 있습니다. 기본값은 `돌쇠야, 이모님`입니다.
호출어 발음 보정은 초성·받침이 같고 모음 하나만 다르게 인식된 경우를 보완합니다. 오반응이 있으면 설정에서 끌 수 있습니다.
별칭은 휴대폰 앱에만 저장하며 HA 이름을 바꾸지 않습니다. 별칭 없는 항목은 제어하지 않습니다.

## 화면이 꺼진 상태

휴대폰 설정 → 앱 → 돌쇠 음성비서 → 배터리에서 **제한 없음**으로 설정하세요.
호출 대기 중에는 마이크 사용 알림이 유지됩니다. 앱의 **대기 중지** 또는 알림의 **중지**로 멈출 수 있습니다.
재부팅·강제 종료 후에는 앱에서 호출 대기를 다시 시작해야 합니다. 통화나 다른 앱의 마이크 사용으로 중단되면 다시 시작하세요.
항상 듣는 기능은 배터리를 사용합니다. 필요할 때만 켜세요.
음성 응답이 안 들리면 휴대폰의 글자 읽어주기 설정에 오프라인 한국어 음성을 설치하세요. 한국어 오프라인 음성이 없으면 응답을 글자로만 표시합니다.

## 구현 범위

- SenseVoice INT8 한국어 모델(2024-07-17), Silero 신경망 음성 구간 감지, sherpa-onnx 1.13.8.
- 음성인식은 휴대폰 내부에서 수행합니다. 마이크 음성을 HA나 외부 음성인식 서버에 업로드하지 않습니다.
- HA에는 HTTPS로 레이블 조회, 상태 조회, 개별 엔티티 서비스 요청만 전송합니다.
- 연결 토큰은 Android Keystore의 AES-GCM 키로 암호화해 앱 전용 저장소에 보관합니다. APK 안에 토큰은 없습니다.
- 명령 직전에 레이블을 다시 조회합니다. 조회에 실패하거나 레이블이 제거되었으면 제어를 중단합니다.
- 스크립트·장면·잠금장치·그룹·전체 장치 일괄 명령과 임의 HA 서비스 실행은 지원하지 않습니다.
- 조명·스위치·토글 도우미·선풍기·커튼·냉난방기·미디어 플레이어의 지원 동작, 센서·이진 센서 상태 조회를 지원합니다.
- 별칭은 중복될 수 없습니다. HA의 서비스 실패를 성공으로 알리지 않습니다.

## 검증과 한계

순수 Java 핵심 검사 36건, Android 에뮬레이터의 네이티브 음성 모델·VAD 실행을 확인했습니다. 합성 음성 호출어 4건과 비호출 문장 2건을 구분했습니다.
합성 한국어 음성은 실제 사람의 목소리·잡음·거리 조건을 대신하지 않습니다. 모델 후보를 비교해 기본 호출어 결과가 더 나았던 SenseVoice 버전을 선택했습니다. 모든 환경에서 최고 정확도를 보장한다는 의미는 아닙니다.
실제 갤럭시의 인식률, 배터리, 화면 잠금 상태, HA 실장치 동작은 아직 사용자 기기에서 검증하지 않았습니다. 시험 모드부터 확인해주세요.

## 소스 재빌드

`python3 prepare-deps.py /원하는/작업폴더`로 공개 모델·라이브러리를 준비한 후 아래 환경 변수를 지정해 `android/build-apk.sh`를 실행합니다.

- `ANDROID_SDK_ROOT`: SDK 36과 build-tools 36.1.0이 설치된 경로
- `VOICE_BUILD_DIR`: 소스 밖의 빌드 경로
- `VOICE_DEPS_DIR`: prepare-deps 출력의 deps 폴더
- `VOICE_ASSETS_DIR`: prepare-deps 출력의 assets 폴더
- `VOICE_KEYSTORE`, `VOICE_STOREPASS`: 직접 만든 서명 키와 비밀번호. 키 별칭은 dolswe-voice.

JDK, zip, Python 3.12 이상이 필요합니다. 비공개 서명 키·비밀번호·연결 토큰은 소스 압축에 포함하지 않습니다.
