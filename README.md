# 돌쇠 음성비서 1.1.4

갤럭시용 별도 앱입니다. 캠핑 장부나 Home Assistant 앱을 열어두지 않아도 됩니다.
Android 10 이상, ARM64 기기용입니다.

## 처음 연결

1. `dolswe-voice.apk`를 휴대폰에 다운로드해 설치합니다.
2. HA 프로필 → 보안 → **장기 액세스 토큰**에서 앱용 토큰을 만듭니다. 토큰은 앱에만 입력하고 다른 사람에게 보내지 마세요.
3. 앱 **설정**에 HA HTTPS 주소, 토큰, **HA에 만들어 둔 레이블 이름**을 입력합니다.
4. **장치 별칭 → HA 장치 목록 불러오기**를 누릅니다.
5. 사용할 항목에 앱에서 부를 이름을 입력하고 **장치 별칭 저장**을 누릅니다. 예: `거실 불`, `안방 선풍기`.
6. **설정 → 지도에서 집 위치·반경 설정**에서 집을 선택하고 반경을 저장합니다. 기본 200m, 50~3,000m를 지정할 수 있습니다. 주소 검색이나 현재 위치 버튼도 사용할 수 있습니다.
7. **호출어 인식 테스트**로 `돌쇠야`, `이모님`의 인식 결과를 확인합니다.
8. **호출 대기 시작**을 누르고 마이크·알림·정확한 위치 권한을 허용합니다. 위치는 앱 사용 중 허용으로 사용할 수 있으며, 시작한 호출 대기의 위치 알림이 유지됩니다.
9. 처음에는 **시험 모드**로 연결만 확인합니다. 실제 제어는 설정에서 시험 모드를 끄고 저장한 뒤 호출 대기를 다시 시작하세요.

토큰을 다시 입력하지 않고 설정만 바꿀 때는 토큰 칸을 비워 둡니다.
레이블은 이름 또는 HA 레이블 ID를 입력할 수 있습니다. 엔티티에 붙인 레이블과 장치에 붙인 레이블을 확인합니다. 장치 레이블은 그 장치의 지원 항목들을 불러옵니다. 그룹은 제외합니다.

## 말하는 예

- `돌쇠야, 거실 불 켜줘`
- `이모님` → “네, 말씀하세요” 후 `안방 선풍기 꺼줘`
- `돌쇠야, 거실 불 밝기 50퍼센트로 맞춰줘`
- `이모님, 에어컨 온도 25도로 맞춰줘`
- `돌쇠야, 거실 불 상태 알려줘`
- `이모님, 침실 커튼 닫아줘`

등록한 별칭을 문장 앞에 말하세요. 한 번에 한 장치씩 제어합니다.
호출어는 설정에서 쉼표로 구분해 1~10개로 바꿀 수 있습니다. 기본값은 `돌쇠야, 이모님`입니다.
호출어 발음 보정은 초성·받침이 같고 모음 하나만 다르게 인식된 경우를 보완합니다. 오반응이 있으면 설정에서 끌 수 있습니다.
별칭은 휴대폰 앱에만 저장하며 HA 이름을 바꾸지 않습니다. 별칭 없는 항목은 제어하지 않습니다.

## 화면이 꺼진 상태

휴대폰 설정 → 앱 → 돌쇠 음성비서 → 배터리에서 **제한 없음**으로 설정하세요.
호출 대기 중에는 마이크 사용 알림이 유지됩니다. 앱의 **대기 중지** 또는 알림의 **중지**로 멈출 수 있습니다.
재부팅·강제 종료 후에는 앱에서 호출 대기를 다시 시작해야 합니다. 통화나 다른 앱의 마이크 사용으로 중단되면 다시 시작하세요.
항상 듣는 기능은 배터리를 사용합니다. 필요할 때만 켜세요.
음성 응답이 안 들리면 휴대폰의 글자 읽어주기 설정에 오프라인 한국어 음성을 설치하세요. 한국어 오프라인 음성이 없으면 응답을 글자로만 표시합니다.

## 구현 범위

- SenseVoice INT8 한국어 모델(2024-07-17), Silero 신경망 음성 구간 감지, sherpa-onnx 1.13.8.
- 음성인식은 휴대폰 내부에서 수행합니다. 마이크 음성을 HA나 외부 음성인식 서버에 업로드하지 않습니다.
- HA에는 HTTPS로 레이블 조회, 상태 조회, 개별 엔티티 서비스 요청만 전송합니다.
- 연결 토큰은 Android Keystore의 AES-GCM 키로 암호화해 앱 전용 저장소에 보관합니다. APK 안에 토큰은 없습니다.
- 명령 직전에 레이블을 다시 조회합니다. 조회에 실패하거나 레이블이 제거되었으면 제어를 중단합니다.
- 스크립트·장면·그룹·전체 장치 일괄 명령과 임의 HA 서비스 실행은 지원하지 않습니다.
- 조명·스위치·토글 도우미·선풍기·커튼·냉난방기·미디어 플레이어·도어록의 지원 동작, 센서·이진 센서 상태 조회를 지원합니다.
- 별칭은 중복될 수 없습니다. HA의 서비스 실패를 성공으로 알리지 않습니다.

## 검증과 한계

순수 Java 핵심 검사 36건, Android 에뮬레이터의 네이티브 음성 모델·VAD 실행을 확인했습니다. 합성 음성 호출어 4건과 비호출 문장 2건을 구분했습니다.
합성 한국어 음성은 실제 사람의 목소리·잡음·거리 조건을 대신하지 않습니다. 모델 후보를 비교해 기본 호출어 결과가 더 나았던 SenseVoice 버전을 선택했습니다. 모든 환경에서 최고 정확도를 보장한다는 의미는 아닙니다.
실제 갤럭시의 인식률, 배터리, 화면 잠금 상태, HA 실장치 동작은 아직 사용자 기기에서 검증하지 않았습니다. 시험 모드부터 확인해주세요.

## 소스 재빌드

`python3 prepare-deps.py /원하는/작업폴더`로 공개 모델·라이브러리를 준비한 후 아래 환경 변수를 지정해 `android/build-apk.sh`를 실행합니다.

- `ANDROID_SDK_ROOT`: SDK 36과 build-tools 36.1.0이 설치된 경로
- `VOICE_BUILD_DIR`: 소스 밖의 빌드 경로
- `VOICE_DEPS_DIR`: prepare-deps 출력의 deps 폴더
- `VOICE_ASSETS_DIR`: prepare-deps 출력의 assets 폴더
- `VOICE_KEYSTORE`, `VOICE_STOREPASS`: 직접 만든 서명 키와 비밀번호. 키 별칭은 dolswe-voice.

JDK, zip, Python 3.12 이상이 필요합니다. 비공개 서명 키·비밀번호·연결 토큰은 소스 압축에 포함하지 않습니다.

## 집에서만 음성 동작

기본적으로 **집 범위 안에서만 음성 동작**이 켜져 있습니다. 호출 대기를 앱에서 한 번 시작하면 위치 확인 알림을 유지합니다. 집 밖이거나 위치가 불명확하면 마이크·음성 모델·음성 처리용 WakeLock을 해제하고, 집 안으로 확인되면 다시 시작합니다. GPS 상시 추적 대신 네트워크 위치와 다른 앱이 확인한 위치를 사용합니다. 위치 반영은 몇 분 지연될 수 있습니다.

최근 5분 내의 위치만 사용하고, 위치 오차 범위까지 집 반경 안에 들어와야 음성이 켜집니다. 집 안에서도 대기 상태라면 위치 기능·정확한 위치 권한을 확인하고 반경을 넓혀보세요. 집 위치·반경은 휴대폰에만 저장합니다. 지도와 주소 검색은 온라인 연결을 사용합니다. 위치 제한을 끄면 어디서나 호출 대기를 사용할 수 있습니다. 집 위치를 바꾸거나 연결 설정을 저장하면 호출 대기를 다시 시작해주세요.

재부팅·강제 종료 후 자동 시작하지 않습니다. 다시 앱에서 호출 대기를 시작해주세요. 실제 갤럭시의 배터리와 잠금 상태·귀가 시 재개 동작은 기기에서 확인이 필요합니다.

## 앱 업데이트

1.1.0부터 앱을 실행할 때 GitHub 최신 배포 정보를 확인합니다. 새 버전이 있으면 다운로드하고, 파일 크기·SHA-256·패키지 이름·버전·기존 앱과의 서명을 검사한 뒤 설치 화면을 엽니다. **최종 설치는 안드로이드에서 사용자가 확인**합니다. 처음에는 돌쇠 음성비서의 알 수 없는 앱 설치 권한 허용이 필요할 수 있습니다. 자동 확인은 설정에서 끌 수 있고, **지금 업데이트 확인**으로 수동 실행할 수 있습니다.

구버전 1.0.x에는 이 기능이 없으므로 1.1.0 APK는 한 번 직접 받아 설치해야 합니다. S25 울트라에서 1.0.3 설치는 사용자가 확인했습니다. 새 버전의 실제 기기 동작은 설치 후 확인이 필요합니다.

다음 배포: 서명된 APK를 만든 뒤 `python3 make-update-info.py signed.apk update.json`을 실행하고 APK와 **update.json**을 같은 버전의 GitHub Release에 업로드해야 앱이 새 버전을 확인할 수 있습니다.

## 도어록 (lock)

1.1.1부터 지정한 레이블의 `lock` 엔티티를 목록에 불러옵니다. **장치 별칭 → HA 장치 목록 불러오기**를 다시 누르고, 예를 들어 `현관문`이라는 별칭을 저장하세요.

- `돌쇠야, 현관문 상태 알려줘`
- `돌쇠야, 현관문 잠가줘`
- `돌쇠야, 현관문 잠금 해제해줘`

잠그기와 상태 조회는 기본 지원합니다. 실제 음성 잠금 해제는 **설정 → 도어록 음성 잠금 해제 허용**을 켜고 설정을 저장해야 합니다. 시험 모드에서는 잠금 해제 옵션을 켜지 않아도 명령 연결만 확인할 수 있습니다.

HA 기기에서 코드를 요구하면 장치 별칭 화면의 해당 도어록 코드 칸에 입력하고 별칭 저장을 누르세요. 코드는 Android Keystore로 암호화해 저장합니다. 빈 칸으로 저장하면 기존 코드를 유지하고, 삭제 체크 후 저장하면 지웁니다. 코드 삭제와 새 코드 입력을 동시에 지정할 수 없습니다. 코드는 음성으로 받거나 읽어주지 않습니다.

‘열어줘’도 잠금 해제로 해석합니다. HA의 별도 래치 개방 동작인 `lock.open`은 실행하지 않습니다. 그룹·전체 일괄 명령은 지원하지 않습니다. 명령 직전 레이블과 집 범위를 재확인합니다. 기기 응답 전송 성공을 실제 잠금 완료로 표시하지 않습니다. 상태 조회로 결과를 확인하세요.

## 짧은 명령 (1.1.2)

별칭 뒤에 켜·꺼·열어·닫아를 짧게 말할 수 있습니다. 도어록은 **켜·닫아 = 잠금**, **꺼·열어 = 잠금 해제**입니다. 커튼은 **켜·열어 = 열기**, **꺼·닫아 = 닫기**입니다. 조명·스위치·선풍기 등은 기존처럼 켜·꺼를 사용합니다. 예: `돌쇠야 현관문 닫아`, `이모님 거실 커튼 꺼`. 도어록의 꺼·열어 명령도 음성 잠금 해제 허용 설정을 따릅니다.

## 한 번에 이어 말하기 (1.1.3)

호출어 뒤에서 쉬지 않고 `이모님거실불켜줘`, `이모님거실등켜줘`, `돌쇠야거실조명꺼줘`처럼 한 번에 말할 수 있습니다. 띄어쓰기는 무시합니다. 조명 별칭이 `거실 불`이면 `거실 등`, `거실 전등`, `거실 조명`도 같은 항목으로 찾습니다. 조명 종류의 엔티티와 불·등·전등·조명으로 끝나는 스위치 별칭에 적용합니다.

장치 별칭에 `거실 불, 메인 조명`처럼 쉼표로 최대 8개의 이름을 넣을 수 있습니다. 음성 응답에는 첫 번째 이름을 사용합니다. 다른 장치와 호환 이름이 겹치면 저장과 명령을 중단하고 구체적인 별칭을 요청합니다. 엔티티 이름을 소리가 비슷하다는 이유로 임의 매칭하지 않습니다.

문자 인식 결과의 붙여쓰기·띄어쓰기와 별칭 처리에 대한 기능입니다. 실제 발음·거리·소음에 따라 음성인식 모델이 다른 단어로 받아쓸 수 있습니다. 호출어 테스트에서 인식된 문장을 확인하고 필요한 별칭을 추가하세요.

## 1.1.4 호출어 앞부분 보존

마이크 입력에서 음성 시작 직전 400ms를 보존하고 200ms의 무음 문맥을 넣습니다. VAD가 잘라낸 음성만 받아쓰기하던 경로에서 ‘돌쇠야’가 누락되는 현상을 재현해 수정했습니다. 음성 버퍼는 16초 크기로 제한하고 집 밖에서는 마이크와 모델을 해제합니다. 호출어 비교 범위를 무조건 넓히지는 않았습니다.

검증은 실제 서비스와 같은 VAD→PCM 보존→한국어 인식 경로를 사용합니다. 합성 음성 검증은 실제 갤럭시에서 사용자의 목소리로 검증한 결과가 아니므로, 업데이트 후 ‘호출어 인식 테스트’로 확인해주세요.

단독 호출 4개 합성 음성 추가 검사에서는 2개만 일치했습니다. 다른 목소리는 ‘同수呀’, ‘에모’로 받아써지는 등 인식 모델 자체의 한계가 남습니다. 이 버전은 전용 호출어 모델로 교체한 버전이 아니며, 실제 기기 호출 정확도를 보장하지 않습니다.
