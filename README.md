# 돌쇠 음성비서 1.2.4

갤럭시용 Home Assistant 음성 제어 앱입니다. **지정한 집 와이파이에 연결되어 있을 때만 휴대폰에서 음성을 인식합니다.** 음성을 외부 서버로 보내지 않습니다. HA 주소·토큰·레이블·별칭은 기존 설정을 유지합니다.
Android 10 이상 ARM64용입니다.

## 처음 연결

1. `dolswe-voice.apk`를 설치합니다. 기존 앱 위에 설치하면 설정이 유지됩니다.
2. HA 프로필 → 보안 → 장기 액세스 토큰에서 앱용 토큰을 만들고 앱 설정에 입력합니다. 기존 토큰을 유지하려면 입력칸을 비워 둡니다.
3. HA HTTPS 주소와 제어를 허용할 **엔티티/장치 레이블 이름**을 입력합니다.
4. 집 와이파이에 연결한 뒤 **설정 → 현재 와이파이를 집으로 지정 → 연결 설정 저장**을 누릅니다. 이름을 직접 입력할 수도 있습니다.
5. **장치 별칭 → HA 장치 목록 불러오기**에서 이름을 지정하고 저장합니다. 별칭 없는 항목은 제어하지 않습니다.
6. **호출 대기 시작**을 누르고 마이크·알림·정확한 위치 권한을 허용합니다.
7. 처음에는 **시험 모드**에서 명령 연결을 확인하세요. 실제 제어는 시험 모드를 끄고 저장한 뒤 호출 대기를 다시 시작합니다.

위치 좌표·지도·집 반경은 필요하지 않습니다. 안드로이드에서 연결된 와이파이 이름(SSID)을 읽으려면 정확한 위치 권한과 휴대폰 위치 기능을 켜야 합니다. 앱은 GPS/네트워크 위치 업데이트를 요청하지 않습니다. [Android WifiInfo 문서](https://developer.android.com/reference/android/net/wifi/WifiInfo)

와이파이는 이름이 **완전히 일치할 때만** 허용합니다. 손님용·다른 집 와이파이, 모바일 데이터, 확인 불가능한 SSID에서는 마이크·음성 모델·CPU 잠금이 해제됩니다. 처음 시작한 서비스의 알림은 재연결 감지를 위해 유지되고, 집 와이파이에 다시 연결되면 호출 대기를 재개합니다. 이 조건은 음성인식 활성화 조건이며 HA 접속 주소를 변경하지 않습니다.

## 야간 음성인식 금지 시간

설정에서 **야간 음성인식 금지 시간 사용**을 켜고, **금지 시작 / 금지 종료**에서 시간을 골라 연결 설정을 저장합니다. 기본 입력 시간은 **22:00~07:00**이고 기능은 기본으로 꺼져 있습니다. 매일 반복하며 자정을 넘기는 시간도 지원합니다. 시작과 종료를 같은 시간으로 저장할 수 없습니다.

금지 시간에는 호출어·마이크 명령·인식 테스트·연속 대화를 모두 멈추고 마이크·음성 모델·CPU 잠금을 해제합니다. 금지 시간이 끝나면 집 와이파이 연결 여부를 다시 확인하고 호출 대기를 재개합니다. 기존 연속 대화는 이어지지 않으며 호출어가 다시 필요합니다. 대기 중지를 직접 누르거나 앱을 강제 종료했다면 자동으로 서비스를 시작하지 않습니다.

휴대폰의 현지 시간대를 따르고, 시간/시간대 변경 시 다음 시작·종료 시각을 다시 계산합니다. 절전 중에는 [안드로이드의 일반 알람](https://developer.android.com/develop/background-work/services/alarms)으로 재확인하며, 시스템 절전 정책에 따라 종료 후 재개가 지연될 수 있습니다. 정확한 알람 특별 권한은 요청하지 않습니다.

## 연속 말하기

- `이모님거실불켜줘`처럼 호출어와 명령을 붙여 말할 수 있습니다.
- 호출어 뒤에 잠깐 쉬고 명령을 이어 말하는 경우 다음 음성 구간을 기다려 연결합니다.
- 첫 응답이 끝나면 `안방 선풍기 꺼줘`처럼 호출어 없이 다음 명령을 말할 수 있습니다.
- 기본 대기는 **응답이 끝난 시점부터 20초**입니다. 설정에서 연속 말하기를 끄거나 5~60초로 조절할 수 있습니다.
- `그만`, `대화 종료`, `취소`, `됐어`로 후속 명령 대기를 끝냅니다. 시간이 지나거나 와이파이가 끊기면 다음 명령에 호출어가 필요합니다.
- 앱이 답하는 동안의 소리는 자기 목소리 재인식을 막기 위해 제외합니다. **응답이 끝난 다음** 이어 말해주세요. 답변 중 끼어 말하기는 지원하지 않습니다.
- 마이크 수집과 인식/HA 처리를 분리해 처리 중 들어온 완성된 음성 구간을 제한된 큐에 보관합니다.

## 장치 이름만 말하기

`이모님 거실 불`처럼 호출어와 장치 별칭까지만 말하면 실행할 때 HA의 현재 상태를 새로 조회해 반대로 전환합니다. 연속 대기 중에는 `안방 선풍기`처럼 이름만 말할 수 있습니다.

- 조명·스위치·선풍기 등: 켜짐 ↔ 꺼짐
- 커튼: 열림 ↔ 닫힘
- 도어록: 잠김 ↔ 잠금 해제. 잠금 해제는 기존 허용 설정과 기기별 코드 설정을 그대로 적용합니다.
- 에어컨: 꺼짐이면 켜고, 냉방·난방 등 동작 모드이면 끕니다. [HA climate 상태](https://www.home-assistant.io/integrations/climate/)
- 미디어 기기: 꺼짐이면 켜고, 켜짐·대기(idle)·재생·일시정지·버퍼링 상태이면 끕니다. [HA media player 상태](https://www.home-assistant.io/integrations/media_player/)
- 버튼은 한 번 누르고, 센서는 상태를 읽습니다.

연결 불가·알 수 없는 상태, 커튼 이동 중, 도어록 잠금/해제 진행 중·걸림 상태에서는 반대로 동작할 방향을 추측하지 않습니다. ‘상태 알려줘’는 그대로 조회만 합니다.

장치 이름 뒤에 짧게 쉬고 ‘켜줘’ 같은 명령을 이어 붙이는 경우를 위해 약 1.2초 추가 음성 구간을 기다립니다. 명시한 명령이 들어오면 해당 명령을 사용합니다. 시험 모드는 반대로 실행할 동작을 안내하고 실제 명령은 보내지 않습니다. 집 와이파이·야간 금지 시간·레이블 제한은 그대로 적용됩니다.

## 장치와 명령

설정된 레이블의 엔티티와 장치에 속한 지원 엔티티를 가져옵니다. 레이블은 이름 또는 ID로 입력할 수 있습니다. 실제 실행 직전에 레이블을 다시 확인합니다. 그룹·와일드카드·임의 서비스는 실행하지 않습니다.

별칭은 쉼표로 최대 8개 입력할 수 있고, 조명은 불·등·전등·조명으로 바꿔 부를 수 있습니다. 별칭이 다른 장치와 겹치면 저장하지 않습니다.

- 조명/스위치/선풍기 등: `켜줘`, `꺼줘`, `상태 알려줘`
- 조명 밝기, 선풍기 속도, 볼륨: `50퍼센트로 맞춰줘`
- 에어컨: `온도 25도로 맞춰줘`
- 커튼: `열어줘`, `닫아줘`, `멈춰줘`
- 도어록: `켜·닫아·잠가줘`는 잠금, `꺼·열어·풀어줘`는 잠금 해제. 잠금 해제는 설정에서 별도로 허용해야 합니다. 필요하면 기기별 코드를 암호화해 저장합니다.
- 버튼: `눌러줘`, `실행해줘`로 [button.press](https://www.home-assistant.io/integrations/button/)를 한 번 실행합니다. 한 번도 누르지 않아 `unknown`인 버튼도 지원합니다.

한 번에 한 장치씩 제어합니다. 기본 호출어는 `돌쇠야, 이모님`이며 설정에서 1~10개로 바꿀 수 있습니다.

## 실행·업데이트

앱 실행 시 GitHub 새 버전을 확인해 APK를 다운로드하고 안드로이드 설치 화면을 엽니다. 최종 설치는 사용자 확인이 필요합니다. 패키지·버전·서명·파일 크기·SHA-256을 확인합니다.

휴대폰 배터리 설정에서 제한 없음으로 설정하고 마이크 사용 알림을 유지해주세요. 강제 종료·재부팅 후에는 앱에서 호출 대기를 다시 시작합니다. 알림의 중지 또는 앱의 대기 중지로 멈출 수 있습니다.

## 음성 인식과 검증 한계

SenseVoice INT8 한국어 모델과 Silero VAD를 휴대폰에서 실행합니다. VAD 시작 전 400ms를 보존하고 200ms의 무음 문맥을 붙여 호출어가 잘리던 경로를 수정했습니다. 호출어 발음 보정은 초성·받침이 같고 모음 하나만 다른 경우만 보완하며 설정에서 끌 수 있습니다.

실제 갤럭시/사용자 음성의 정확도는 미검증입니다. 합성 음성에서도 목소리에 따른 단독 호출 오인식이 남습니다. `글쎄야·벌쎄야·벌 수야`를 무조건 호출어로 허용하지 않습니다. ‘호출어 인식 테스트’로 확인해주세요.

버전별 검증 결과는 `TEST_RESULTS_*.json`에 있습니다. 과거 위치/지도 테스트는 당시 버전의 기록이고, 현재 음성 시작 조건은 와이파이입니다.

## 1.2.3 업데이트 확인 수정

앱을 처음 실행할 때와 다른 화면에서 앱으로 돌아올 때 업데이트를 확인합니다. 반복 복귀는 1분 간격으로 제한하며 수동 확인은 즉시 실행합니다. 설정에서 설치 버전과 마지막 확인 결과를 볼 수 있습니다. 다운로드한 APK의 해시·앱 서명·버전을 검사하고 안드로이드 설치 화면을 엽니다. 최종 설치 확인은 사용자가 해야 합니다. 1.2.1 등 이전 버전은 이번 APK를 한 번 직접 설치해야 이 수정이 적용됩니다.

## 1.2.4 와이파이 연결 안정성

연결 확인 도중 잠깐 연결 없음으로 노출되던 경쟁 상태를 없앴습니다. 확인이 완료된 연결 상태를 한 번에 반영하고, 안드로이드 네트워크 알림에서 제공한 연결별 정보를 사용합니다. 다른 네트워크의 해제 알림은 현재 집 와이파이를 끊지 않습니다. 인터넷 유효성 검사 없이 집 와이파이 연결로 음성인식을 허용하며, 실제 연결 해제·다른 SSID·위치 권한 해제·야간 금지 시간에는 계속 차단합니다. 집 와이파이에 다시 연결되면 자동으로 호출 대기를 재개합니다.

구현 참고: [Android NetworkCallback 공식 문서](https://developer.android.com/reference/android/net/ConnectivityManager.NetworkCallback). 콜백 안에서 동기 연결 조회를 실행하지 않고 별도 작업으로 연결 상태를 반영합니다.
